# our-SESSION サイトマップ

> アプリ全体の画面・ドロワー・オーバーレイの一覧と遷移関係。
> Claude Code はこのマップを **全画面実装の基準** として使うこと。

## 画面区分の定義

| 区分 | 説明 | 例 |
|---|---|---|
| **画面 (Screen)** | ボトムナビで切り替わる主要画面 | タイムライン、マイページ |
| **オーバーレイ (Overlay)** | 全画面を覆う、右からスライドイン | プロフィールページ、設定、保存一覧 |
| **ドロワー (Drawer)** | 下から上にスライドイン、画面の80〜90%を覆う | アンサー投稿、プロフィール編集 |
| **シート (Sheet)** | 下から上にスライドイン、小さめ(40〜60%) | 通報、フィルタ |
| **ダイアログ (Dialog)** | 中央モーダル | ブロック確認、削除確認 |
| **トースト (Toast)** | 画面下部に一時表示 | 完了通知 |

## 全画面マップ(階層構造)

```
[ルート]
│
├── 認証前
│   ├── ランディング(タイムライン閲覧のみ可能、ログインゲート付き)
│   └── オンボーディング (登録直後のみ)
│       ├── Step 1: ニックネーム
│       ├── Step 2: 楽器 + 練習中トグル
│       ├── Step 3: エリア
│       └── Step 4: ウェルカム
│
└── 認証後 (ボトムナビ 4項目)
    │
    ├── 📰 タイムライン (Screen)
    │   ├── 🔍 検索(現在UIのみ)
    │   ├── 🔔 通知 (Overlay)
    │   ├── 🎚 フィルタ (Sheet) — 楽器/ジャンル/エリア
    │   ├── セッションカード × N
    │   │   ├── サムネタップ → 他人のプロフィールページ (Overlay)
    │   │   ├── ボタン「アンサーを送る」→ アンサー投稿 (Drawer)
    │   │   ├── ブックマーク 🔖 → 保存トグル
    │   │   └── ⋯ メニュー → アクションシート (Sheet)
    │   │       ├── この投稿を通報する → 通報シート (Sheet)
    │   │       └── ○○さんをブロック → ブロック確認 (Dialog)
    │   └── 本文タップ → 折りたたみ展開
    │
    ├── ➕ 投稿 (Screen) ← フローティングボタン or ナビから
    │   ├── 安心ブロック1: 同じ○○好きが○人います (孤独感解消)
    │   ├── 安心ブロック2: 公開範囲: 全員 / 足あとは残りません
    │   ├── MP3アップロードゾーン
    │   │   ├── 🎤 その場で録音する (主役)
    │   │   │   └── カウントダウン → 録音中 → プレビュー → 送信
    │   │   └── 📁 ファイルから選ぶ (代替)
    │   ├── タイトル入力 (30字)
    │   ├── 本文入力 (150字、任意)
    │   ├── タグ選択(楽器/ジャンル/エリア)
    │   └── 「公開」→ トースト「あなたの音、届きました」→ タイムラインへ
    │
    ├── 💬 メッセージ (Screen)
    │   ├── 会話一覧
    │   │   ├── 自分が投稿主のカード(ホスト、赤マーク)
    │   │   ├── 自分が参加中のカード(承認済み)
    │   │   └── 申請中のカード(承認待ち、時計マーク)
    │   └── 各行タップ → チャットルーム (Screen 遷移)
    │       ├── 上部: セッションスニペット
    │       ├── 未承認アンサー(↳マーク)
    │       │   ├── 承認 → 「○○さんと、会えそうですね」(システムメッセージ)
    │       │   └── あとで → 保留中Nバーに移動
    │       ├── 区切り線
    │       ├── メッセージスレッド
    │       ├── パート投票(楽器バブル)
    │       └── クイックリプライタブ + 入力欄
    │
    └── 👤 マイページ (Screen)
        ├── 上部: 🔖保存(セッションカード保存一覧 Overlay)
        ├── 上部右: 編集 → プロフィール編集 (Drawer) / ⚙設定 (Overlay)
        ├── ヒーロー(アバター/名前/エリア/🔰練習中)
        ├── 情報カード(楽器/ジャンル/好きな曲/自己紹介)
        ├── 💡「○○さんのプロフィールと似ている人」スライダー (マイページのみ)
        ├── SESSION CARDS 見出し
        └── 自分のセッションカード × N
            └── ⋯ メニュー → 編集 / 削除

## オーバーレイ・ドロワー・シート 詳細

### Overlay (右からスライドイン)

| 名前 | 入口 | 内容 |
|---|---|---|
| **他人のプロフィールページ** | カードのサムネタップ等 | アバター/名前/エリア/練習中/情報カード/その人のセッションカード一覧 ※サジェスト無し |
| **通知** | タイムライン右上の🔔 | 日別の通知リスト、タップで該当画面へ |
| **設定** | マイページ⚙ | 通知/テーマ/言語/アカウント/法務/サポート/プレビュー |
| **保存一覧** | マイページ🔖 | 自分が保存(ブックマーク)したセッションカードのリスト |
| **オフライン画面** | 設定>プレビュー / ネット切れ時自動 | 「音が遠くなりました」フォールバック |

### Drawer (下からスライドイン、90%高さ)

| 名前 | 入口 | 内容 |
|---|---|---|
| **アンサー投稿** | カードの「アンサーを送る」 | MP3録音/アップロード + 一言メッセージ |
| **プロフィール編集** | マイページの「編集」 | ニックネーム/アバター/練習中/自己紹介/楽器/ジャンル/好きな曲/エリア/SNS |
| **認証(Auth Gate)** | ログイン必須操作の入口 | Google/Apple/メール |

### Sheet (下からスライドイン、40〜60%)

| 名前 | 入口 | 内容 |
|---|---|---|
| **フィルタ** | タイムラインのフィルタチップ | 楽器/ジャンル/エリアの複数選択 |
| **カードアクション** | カードの⋯ | 通報する/ブロックする(他人) or 編集/削除(自分) |
| **プロフィールアクション** | 他人プロフィールの⋯ | 通報する/ブロックする |
| **通報シート** | アクションシート > 通報 | 6カテゴリラジオ + 補足コメント |

### Dialog (中央モーダル)

| 名前 | 入口 | 内容 |
|---|---|---|
| **ブロック確認** | アクションシート > ブロック | 内容説明 + OK/キャンセル |
| **カード削除確認** | カード⋯ > 削除 | 警告 + OK/キャンセル |
| **アカウント削除確認** | 設定 > アカウント削除 | 警告 + OK/キャンセル |

### Toast (3.8秒で自動消滅)

| 発火条件 | 文言 |
|---|---|
| 投稿完了 | あなたの音、届きました🎵 / 仲間が見つかったらお知らせします |
| アンサー送信完了 | あなたの音、届きました🎵 / 相手が聴いてくれたら、メッセージでつながれます |
| プロフィール更新 | プロフィールを更新しました |
| 認証完了(登録) | ようこそ🎵 / まずは気になる人の音源を聴いてみよう |
| 認証完了(ログイン) | ようこそ🎵 / おかえりなさい |
| ログアウト | ログアウトしました |
| 通報完了 | 通報を受け付けました / 運営が確認のうえ、適切に対応します |
| ブロック完了 | ○○さんをブロックしました / 視界から消えます。設定から解除できます |
| ようこそ(オンボード後) | はじめまして、○○さん / 気になる人の音源を聴いてみよう |

## 認証ゲートの挙動

未ログインで以下のアクションを試みると、**認証ドロワー** (Drawer) が下から出る:

- 投稿する
- アンサーを送る
- ハート保存
- メッセージ画面を見る
- マイページを見る
- 通知を見る

**閲覧だけ**(タイムライン・他人プロフィール・音源試聴)はログイン不要。

## ボトムナビの仕様

```
[📰 タイムライン] [➕ 投稿] [💬 メッセージ] [👤 マイページ]
```

- フローティングピル形状(画面下から浮いた角丸の長方形)
- インジケーターが現在地に応じて左右にスプリングアニメ
- 「➕ 投稿」は中央寄りで、未ログイン時はゲート発火

---

## 主要な遷移パターン

### A. タイムラインから音源を聴いて投稿主と話したくなる(基本動線)

```
タイムライン
  → カードの音源を聴く
  → サムネタップ → 他人のプロフィールページ(Overlay)
  → そのカードのアンサーボタン → アンサー投稿(Drawer)
  → MP3 + メッセージを送る → トースト + ドロワー閉じる
  → 投稿主が承認すると → メッセージ画面に新しいチャットルーム
  → 「会えそうですね」のシステムメッセージ
  → スタジオの段取りをチャットで決める → リアルセッションへ
```

### B. 投稿する流れ

```
タイムライン下部の「➕ 投稿」(または右上のフローティング)
  → 未ログインなら認証ドロワー
  → 認証完了 → オンボーディング(登録直後のみ)
  → 投稿フォーム(安心ブロック2つを上部に表示)
  → MP3録音 or ファイル選択 → 進捗バー → 成功
  → タイトル/本文/タグ
  → 公開
  → トースト + タイムラインへ
```

### C. 安全機能(通報・ブロック)

```
気になるユーザーやカードに遭遇
  → カードの⋯ または プロフィールの⋯ → アクションシート
  → 通報を選ぶ → 通報シート(6カテゴリ + 補足) → 送信 → トースト
  または
  → ブロックを選ぶ → ブロック確認ダイアログ → OK → トースト
```

## 画面間の Z-index 階層

```
[zIndex]
100: Toast(最前面)
 95: オフライン画面
 90: トースト基本
 85: ドロワー(アンサー投稿・プロフィール編集・認証)
 80: オンボーディング
 70: オーバーレイ(プロフィール・設定・保存一覧・通知)
 66: シート(通報・フィルタ・アクション)
 65: シートバックドロップ
 60: ダイアログ
 50: フローティングナビ
 10: 通常画面
  1: オーロラ(背景アニメ)
  0: 背景
```

## 設計の注意点(プロト準拠)

1. **画面遷移時のオーロラ継承**: オーバーレイ・ドロワーでも背景のオーロラは継続して見える(完全な不透明にしない)
2. **モーダルのバックドロップ**: 黒の半透明 + `backdrop-filter: blur(6px)`
3. **戻る/閉じるの一貫性**:
   - オーバーレイ: 左上に「←」
   - ドロワー: 左上に「キャンセル」テキスト or 上部のハンドル
   - シート: 上部のハンドル or 左上に「キャンセル」
   - ダイアログ: 右上に「×」 or 「キャンセル」ボタン
4. **アニメーション**:
   - オーバーレイ: 右からスライド(0.3s ease-out)
   - ドロワー/シート: 下からスライド(0.35s cubic-bezier(0.4,0,0.2,1))
   - ダイアログ: フェード + わずかにスケール
   - トースト: 下からスライド + フェード(0.32s/0.4s)

## 受け入れ確認

実装時、Claude Code はこのサイトマップを開いて:

- [ ] 全ての画面・オーバーレイ・ドロワー・シートが存在するか
- [ ] それぞれの入口(発火元)が正しいか
- [ ] Z-index の順序が守られているか
- [ ] 認証ゲートが必要な操作に正しく挟まっているか
- [ ] トーストの発火条件と文言がプロトと一致しているか

を確認すること。
