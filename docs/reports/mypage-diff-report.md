# マイページ 実装差分レポート

> 現在の実装スクショと、プロト(`our-session-modern.html`)・仕様書(`profile-screen-spec.md`)・サイトマップ(`sitemap.md`)を比較した結果。
> Claude Code は **すべて**を修正すること。修正後、最後の §チェックリスト を確認すること。

---

## ❌ 致命的な構造問題

### 問題1: マイページに「設定/ログアウト/ブロック中」を直接表示している

**現状**: マイページの下部に「保存した音源」「ブロック中」「設定」「ログアウト」が直接見えている。

**正解**: これらは**マイページに表示しない**。以下のように分離:

```
マイページに直接表示するもの:
✅ ヒーロー(アバター/名前/エリア/練習中バッジ)
✅ 情報カード(楽器/ジャンル/好きな曲/自己紹介)
✅ サジェスト「○○さんのプロフィールと似ている人」
✅ 自分のセッションカード一覧

マイページに表示しないもの(別オーバーレイへ):
❌ 保存した音源 → ヒーロー左上の「🔖 保存」ボタンタップで「保存一覧オーバーレイ」を開く
❌ ブロック中ユーザー一覧 → 「⚙ 設定」オーバーレイ内の「ブロック一覧」項目から
❌ 各種設定(通知/テーマ/言語など) → 「⚙ 設定」オーバーレイの中
❌ ログアウトボタン → 「⚙ 設定」オーバーレイ内の一番下
```

**修正アクション**:
1. マイページから「保存した音源」「ブロック中」「設定」「ログアウト」セクションを**削除**
2. 「保存一覧オーバーレイ」コンポーネントを作成(右からスライドイン)
3. 「設定オーバーレイ」コンポーネントを作成(右からスライドイン)
4. 設定オーバーレイの中身は CLAUDE.md と sitemap.md に従う

### 問題2: ヒーロー右上の構造が違う

**現状**: 左上に「🔖 保存」、右上に「✏️ 編集」だけ。**設定アイコンが見えない**。

**正解**: 
```
左上: [🔖 保存] ← 保存一覧オーバーレイを開く
右上: [✏️ 編集] [⚙ 設定] ← 編集ドロワー / 設定オーバーレイ
```

**修正**: 「編集」ボタンの右隣に「⚙(歯車)」アイコンの円形ボタンを追加。タップで設定オーバーレイを開く。

---

### 問題3: ボタンが目立ちすぎる(赤すぎる)

**現状**: 「保存」「編集」ボタンが赤いボーダー + 赤文字で強調されている。

**正解**: これらは**控えめなテキストボタン**。プロトでは:
- 背景: `var(--card)` (半透明グレー)
- ボーダー: `var(--border)` (薄い白)
- 文字色: `var(--text2)` (グレー)
- 高さ低め、角丸 14-16px

→ **赤じゃない**。目立たせない。主役は中央のアバターと名前。

---

### 問題4: 情報カードが不完全

**現状**: 「パート・楽器」セクションだけ表示。**ジャンル/好きなアーティスト・曲/自己紹介が無い**。

**正解**: 情報カードは **4セクション** が縦に並ぶ:
```
┌────────────────────────────┐
│ パート・楽器                  │
│ [Vo.] [Gt.]                  │  ← 赤い「accent」タグ
│ ─────────────                │
│ ジャンル                      │
│ [Folk] [Singer-Songwriter]   │  ← 通常グレータグ
│ [Country]                    │
│ ─────────────                │
│ 好きなアーティスト・曲          │
│ [Katie Melua] [aiko] ...     │  ← 通常グレータグ
│ ─────────────                │
│ 自己紹介                      │
│ 学生の頃バンドで...           │  ← bio-text
└────────────────────────────┘
```

**修正**: profileデータから genres、favoriteArtists、bio を取得して表示。空の場合の処理も入れる。

## ⚠️ 中程度の問題

**現状**: ユーザー「haruo」のエリア「奈良」の右側に練習中バッジが無い。

**正解**: ユーザーの `isPractice` が true なら、エリア表示の隣に「🔰 練習中」バッジを表示。

.beginner-badge {

  font-size: 10px;

  letter-spacing: 0.3px;
  background: linear-gradient(135deg, #fff89a 0%, #ff9a5a 100%);
  color: #3a2a00;
  padding: 2px 8px;
  border-radius: 8px;
  margin-left: 6px;

→ **黄→オレンジのグラデーション** + **濃い茶色の文字**

### 問題6: サジェストのカードが1人だけ

**現状**: 「むっち」1人だけ表示。

**正解**: 共通点スコアでスコア順に**最大8人**表示。
- スコアロジックは `profile-screen-spec.md §6` 参照
- 自分は除外
- 自分以外のユーザーが少ない場合は出るだけ全部
- 1人しかいないように見えるなら、ダミーデータが少なすぎる可能性

**修正**: 開発中のシードデータに、複数のテストユーザーを入れる。プロトでは8人(あゆみ・たくみ・ゆうき・はるか・みゆき・FUMIFUMI・REINA・やまさん)入っていた。

---

### 問題7: 練習中ドット(サジェストカード内)の色が違う

**現状**: サジェストカードの「むっち」のアバター右下のドットが**緑色**(または黄緑)。

**正解**: **黄→オレンジのグラデーション**(練習中バッジと同じ色)。

```css
.suggest-beginner-dot {
  background: linear-gradient(135deg, #fff89a 0%, #ff9a5a 100%);
  border: 2px solid var(--bg);  /* 背景色で縁取り */
  /* ... */
}
```

中の絵文字: **🔰**(初心者マーク)

---

### 問題8: セッションカードに「いま○人が聴いています」がない

**現状**: 波形プレイヤーの下に何もない。

**正解**: 波形プレイヤーの**直下**に、緑のドット + 「いま○人が聴いています」表示。

```html
<div class="listening-now">
  <span class="listening-dot"></span>
  <span>いま<span class="listening-count">3人</span>が聴いています</span>
</div>
```

```css
.listening-now {
  display: flex; align-items: center; gap: 6px;
  margin-top: 7px;
  font-size: 10.5px;
  color: var(--text3);
}
.listening-dot {
  width: 6px; height: 6px;
  border-radius: 50%;
  background: #7ec88a;
  animation: listeningPulse 2.2s ease-in-out infinite;
}
.listening-count {
  color: var(--text2);
  font-weight: 600;
}
```

※ 0人の場合は表示しない(CLAUDE.md §4 安心装置参照)

---

### 問題9: 自分のセッションカードに「⋯」メニューが無い

**現状**: カードの右上に⋯メニューが見えない。

**正解**: 自分のカードの右上に「⋯(more-horizontal)」アイコンが配置されているべき。タップで「編集」「削除」のアクションシート。

**注意**: 他人のプロフィールページで見るセッションカードには **⋯メニュー = 通報/ブロック** で、自分のカードでは **⋯メニュー = 編集/削除**。役割が違うので分岐すること。

---

### 問題10: 自分のセッションカードのフッターが違う

**現状**: カードのフッターに「(アバター) haruo」だけ表示されている。

**正解**: 
- **自分のカード(マイページで見ているとき)**: フッターには名前すら不要、もしくは控えめに表示。「アンサーを送る」ボタンも不要(自分にアンサーは送らない)、保存ボタンも不要(自分のカードは保存しない)。
- **他人のカード(他人のプロフィールページで見ているとき)**: フッターに アバター + 名前 + 保存🔖 + 「アンサーを送る」ボタン

→ 「自分のカード/他人のカード」で**カードの末尾部分の構造が違う**ので、`isOwn` プロパティで分岐すること。

## 修正の優先順位

1. **構造問題から**(問題1, 2): マイページから余計なものを削除し、オーバーレイに移す
2. **情報の完全性**(問題4, 6): 情報カードの4セクション、サジェスト複数表示
3. **見た目の細部**(問題3, 5, 7, 8, 9, 10): バッジ・ドット・控えめなボタン・listening-now など

順番にやれば、最終的にプロトと一致するはずです。
