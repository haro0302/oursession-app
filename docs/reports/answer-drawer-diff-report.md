# アンサー投稿ドロワー 実装差分レポート

> 現在の実装スクショと、プロト(`our-session-modern.html`)・仕様書(`answer-drawer-spec.md`)を比較した結果。
> Claude Code は**すべて**を修正すること。

---

## ❌ 致命的な問題

### 問題1: ヘッダーの構成が違う

**現状**: 「アンサーを送る | ×」の2要素のみ

**正解**: 「キャンセル | アンサーを送る | 送信」の3要素

```
左:   [キャンセル] ← テキストボタン
中央: アンサーを送る ← タイトル
右:   [✈️ 送信]   ← 紙飛行機アイコン + テキスト、必須項目で活性化
```

**修正**:
- ×ボタンを削除
- 左に「キャンセル」テキストボタンを追加
- 右に「送信」ボタン(紙飛行機アイコン + テキスト)を追加
- 送信ボタンは初期は灰色、必須項目すべて入力で `.ready` クラスが付いて赤に

**仕様書参照**: `answer-drawer-spec.md §4`

---

### 問題2: アンサー先カードが「タイトルのみ」になっている

**現状**: 「↳ 2人からリクエスト受けた時テスト」のテキストのみ

**正解**: **赤い枠のカード**として表示、3つの要素を含む:

```
   ┌─────────────────────────┐
↳ │ アンサー先              │  ← 赤い小さなラベル
   │ 山下達郎「Sparkle」コピー│  ← タイトル(太字)
   │ 👤 REINAさん            │  ← 投稿者名(アバターアイコン付き)
   └─────────────────────────┘
   ↑ ↳マークがカード左外側
```

**現状で欠けているもの**:
- ❌ 赤い枠線のカード化(線がない、テキストだけ)
- ❌ 「アンサー先」の赤い小さなラベル
- ❌ 投稿者名(「REINAさん」など)の表示
- ❌ アバターアイコン(👤)
- ❌ ↳マークがカード左外側にぶら下がる構造

**重要**: ここが「誰に何を返すのか」を明確にする**最重要の情報**。タイトルだけだと「リプライ先」が弱い。

**仕様書参照**: `answer-drawer-spec.md §5`

**実装例**:

```tsx
<div className="ad-target">
  <div className="ad-target-lbl">アンサー先</div>
  <div className="ad-target-title">{cardTitle}</div>
  <div className="ad-target-user">
    <UserIcon />
    <span>{userName} さん</span>
  </div>
</div>
```

```css
.ad-target {
  position: relative;
  background: var(--card);
  border: 1px solid var(--red-border);    /* 赤い枠 */
  border-radius: 16px;
  padding: 13px 14px 13px 16px;
  margin-bottom: 20px;
  margin-left: 14px;
}
.ad-target::before {
  content: '↳';
  position: absolute;
  left: -14px; top: 13px;                  /* 左外側にぶら下げる */
  font-size: 18px;
  color: var(--red2);
}
.ad-target-lbl {
  font-size: 9px; font-weight: 700;
  color: var(--red2);                      /* 赤いラベル */
  text-transform: uppercase;
  letter-spacing: 0.5px;
  margin-bottom: 4px;
}
```

### 問題3: 音源セクションのラベルがない

**現状**: 「あなたの演奏音源」「必須・90秒/5MBまで」のラベル行が**ない**。

**正解**: 各セクションの上に必ずラベルが付く:

```
あなたの演奏音源      必須・90秒/5MBまで   ← このラベル行が無い
[🎤 その場で録音する]
       ── または ──
[ファイルから選ぶ]
```

**修正**:

```html
<div className="ad-label">
  <span>あなたの演奏音源</span>
  <span className="ad-label-req">必須・90秒/5MBまで</span>
</div>
```

**仕様書参照**: `answer-drawer-spec.md §6-1`

### 問題4: 録音ボタンのテキストが「録音する」になっている

**現状**: 「録音する」(マイクアイコンは中央、テキストは下)

**正解**: 「**その場で録音する**」+ サブテキスト「スマホのマイクで90秒まで」

- マイクアイコンは**左**(右にテキスト2行)
- メインテキスト「その場で録音する」(15px, 700, 白)
- サブテキスト「スマホのマイクで90秒まで」(11px, 半透明白)

**修正**: 投稿ページと同じ `rec-start` コンポーネントを使う(または共通化)。

**仕様書参照**: `answer-drawer-spec.md §6-2`

### 問題5: ファイル選択ボタンがフラットすぎる

**現状**: 「ファイルから選ぶ」+ 「MP3・5MB以下・90秒以内」の**細いフラットなボタン**

**正解**: **破線囲みの大きなドロップゾーン**(投稿ページと同じスタイル):

```
┌╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴┐
╎                          ╎
╎     ↑(赤い円)            ╎    ← アップロードアイコン(円形バッジ)
╎                          ╎
╎     ファイルから選ぶ        ╎    ← 太字
╎                          ╎
╎     MP3 (90秒・5MBまで)   ╎    ← サブテキスト
╎                          ╎
└╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴╴┘
```

**修正点**:
- ❌ 「MP3・5MB以下・90秒以内」(現在の表記)
- ✅ 「MP3 (90秒・5MBまで)」(プロトの表記、括弧を使う)
- 破線囲み(`border: 1.5px dashed var(--border2)`)
- 中央にアップロードアイコン(円形)
- ホバー時に枠が赤くなる

**仕様書参照**: `answer-drawer-spec.md §6-3`

---

### 問題6: メッセージラベルが「ひとこと」になっている

**現状**: 「ひとこと(任意)」

**正解**: 「**一言メッセージ**」(右側に「必須・150字以内」)

**重要な違い**:
- ❌ 「ひとこと」(プロトは「一言メッセージ」)
- ❌ 「(任意)」(プロトは**必須**)

**理由**: 
- 「ひとこと」だと短い言葉を期待してしまう。150字書けるなら「一言メッセージ」の方が幅を感じる
- アンサーは「相手にお願いするアクション」なので、**音源だけ送るのは失礼**。一言添えるのが必須。投稿主の判断材料にもなる

**仕様書参照**: `answer-drawer-spec.md §8-3`

---

### 問題7: placeholder が違う

**現状**: 「よろしくお願いします!など、気軽に書いてみてください。」

**正解**: 「**どんな思いでこの曲をやりたいか、自分の演奏のアピールなどを書いてみよう。**」

**理由**:
- アンサーで伝えたいのは「**曲への思い**」と「**自分のアピール**」の両方
- 「よろしくお願いします」だけでは情報が薄い
- 「〜してみよう」で背中を押す(CLAUDE.md トーン)

**修正**: placeholder テキストを差し替え。

---

### 問題8: 文字数カウンタが無い

**現状**: 入力欄に文字数表示なし

**正解**: 入力欄右下に「**0 / 150**」のカウンタ。超えたら赤(`over`クラス)

**修正**:

```tsx
<div className="ad-textarea-wrap">
  <textarea 
    placeholder="..."
    onInput={(e) => updateCounter(e.target.value)}
  />
  <div className={`ad-counter ${overLimit ? 'over' : ''}`}>
    {count} / 150
  </div>
</div>
```

---

### 問題9: 下部に「アンサーを送る」ボタンがある

**現状**: 画面下部に灰色の「アンサーを送る」ボタン(非活性状態)

**正解**: 下部のボタンは**不要**。送信は**ヘッダー右の「送信」ボタン**で実行。

**修正**: 下部の「アンサーを送る」ボタンを削除。

**理由**: 投稿ページと同じパターン。ヘッダーで完結させる。
