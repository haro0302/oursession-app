# メッセージ画面 実装差分レポート

> 現在の実装スクショ(メッセージ一覧 + チャット詳細)と、プロト(`our-session-modern.html`)・仕様書(`messages-screen-spec.md`)を比較した結果。
> Claude Code は**すべて**を修正すること。

---

## ❌ 致命的な問題

### 問題1: ボトムナビが間違っている

**現状**: 「家🏠 / + / 🔔ベル / 👤人」の構成。メッセージタブが**無い**(ベルになっている)。

**正解**: 4項目「**タイムライン / 投稿+ / メッセージ💬 / マイページ👤**」

```
正しい構成:
[🏠 タイムライン] [➕ 投稿] [💬 メッセージ] [👤 マイページ]
```

**修正**:
- ベルアイコン(`bell`)→ メッセージアイコン(`message-square` or `message-circle`)
- 「メッセージ」と「通知」を**別物として扱う**
- 通知は**タイムライン画面の右上のベルアイコン**から開くオーバーレイ(ナビには無い)

→ Claude Codeに「**ナビゲーション構造を sitemap.md に従って修正してください**」と指示

---

### 問題2: タイトルが「通知」になっている

**現状**: メッセージ画面のヘッダーが「**通知**」となっている。

**正解**: 「**メッセージ**」

**修正**: タイトルテキストを差し替えるだけ。ただし、これは問題1と関連しているので **「通知」画面と「メッセージ」画面を実装上混同している可能性**がある。両画面の概念的な違いを Claude Code に伝える必要がある:

- **メッセージ画面**: チャットルームの一覧(セッションカード単位)、ボトムナビからアクセス
- **通知画面**: 新着アンサー・承認・メッセージ等のアラート一覧、タイムラインの🔔から開くオーバーレイ

---

### 問題3: 「チャット中」というセクションラベルがある

**現状**: メッセージ一覧の上部に「**チャット中**」というラベルがある。

**正解**: そんなラベルは**無い**。リストは1つで、すべての状態(host/pending/guest/empty)が混在して時系列で並ぶ。

**修正**: 「チャット中」のサブセクション分けを削除。フラットなリスト構造に。

---

### 問題4: メッセージ一覧の行構造がシンプルすぎる

**現状**: 「(アバター) 名前さんと / タイトル」と「チャットへ→」リンクだけ。

**正解**: 5つの要素が必要:

```
┌──────────────────────────────────────┐
│ 👤●  山下達郎「Sparkle」  5分前      │
│      新しいアンサー · 2件          2 │
└──────────────────────────────────────┘
   ↑    ↑                  ↑          ↑
役割マーク タイトル          時間     未読バッジ
                プレビュー
```

**欠けている要素**:
- ❌ アバター右下の**役割マーク**(host/pending/guest)
- ❌ **時間表示**(5分前 / 30分前 / 1時間前 / 昨日 / 2日前)
- ❌ **プレビュー行**(最新メッセージ or ステータス)
- ❌ **未読バッジ**(赤い丸の数字)

**修正**: `messages-screen-spec.md §1-3, §1-4, §1-5, §1-6` の構造を完全実装。

---

### 問題5: チャットルームの上部スニペットが無い

**現状**: チャット詳細画面は **タイトル → 直接メッセージ** という構造。

**正解**: チャットルームの上部に必ず**セッションスニペット**(カードの縮小版)が表示される。

```
[← テスト260612]
┌─────────────────────────┐
│ 🎵 テスト260612            │
│   主催 · あなた           │  ← これが現在無い
│  [▶] ▮▮▮▮▮▮ 0:00/1:30   │     セッションの音源も再生可能
└─────────────────────────┘
```

**なぜ必要か**: 
- 「**今、何の曲の話をしているのか**」を常に明示
- セッションカード単位のチャットというサービスの本質を体現
- 音源を聴き直しながら相談できる

**修正**: チャットルーム上部に `.chat-session-snippet` を必ず表示。

---

### 問題6: チャットルームに承認UI・アンサーカードが無い

**現状**: チャット詳細は **単純なメッセージバブルだけ**。

**正解**: チャットルームには以下のセクションが存在する:

```
[ヘッダー]
[セッションスニペット]
[未承認アンサーカード] ← ホスト視点で承認待ちのアンサーが並ぶ
[保留中バー] ← 「あとで」したアンサーが折りたたまれる
[─── チャット ───] ← 区切り線(承認後に出現)
[メッセージスレッド]
[クイックリプライタブ]
[入力欄]
```

**欠けているもの**:
- ❌ 未承認アンサーカード(音源 + 一言メッセージ + あとで/承認するボタン)
- ❌ 保留中バー(折りたたみ式)
- ❌ チャット区切り線
- ❌ クイックリプライタブ(挨拶する / 担当は? / 日程は? / スタジオは?)

**修正**: `messages-screen-spec.md §2` の全コンポーネントを実装。

---

### 問題7: ヘッダーに参加人数表示が無い

**現状**: チャット詳細のヘッダーは「← タイトル」だけ。

**正解**: 右側に **👥 N(参加人数)** がある。承認するたびに +1 される。

**修正**: ヘッダー右に `chat-header-members` 要素を追加。

---

## ⚠️ 中程度の問題

### 問題8: メッセージのバブルデザインが微妙にずれている

**現状**:
- 相手のバブル: グレー枠線の角丸長方形
- 自分のバブル: 赤い丸い枠

**プロトとの違い**:
- 相手バブルの**角の取り方**が違う(プロトは左上だけ4px、他は18pxで「吹き出し感」を出す)
- 自分バブルの**シャドウ**が無い(プロトは赤いほのかな影で浮き上がり感)
- バブルの**最大幅80%**制限が無さそう

**修正**: `messages-screen-spec.md §2-8` のCSSを反映。

```css
.chat-msg.other .chat-msg-bubble {
  border-radius: 4px 18px 18px 18px;  /* 左上だけ尖らせる */
}
.chat-msg.self .chat-msg-bubble {
  border-radius: 18px 4px 18px 18px;  /* 右上だけ尖らせる */
  box-shadow: 0 3px 10px rgba(232,74,95,0.3);  /* 赤い影 */
}
```

### 問題9: メッセージの「名前」表示位置

**現状**:
- 相手: バブルの上に名前
- 自分: 名前**なし**

**プロト**:
- 相手: バブルの上に名前(左寄せ)
- 自分: バブルの**下**に「あなた」(右寄せ、控えめ)

**修正**: 自分側にも「あなた」のラベルを追加(または無くてもOK、ただし配置が違う)

---

### 問題10: 「メッセージを入力...」の表記

**現状**: プレースホルダーが「メッセージを入力...」と最後に「...」が付いている

**正解**: 「メッセージを入力」(...なし、シンプルに)

**修正**: プレースホルダー文言を統一。

---

### 問題11: アバターアイコンの色が違う

**現状**: 相手のアバターが「音符アイコン(紫っぽい)」で表示されている。

**正解**: アバターは **`feather: user` アイコン** がデフォルト。音符アイコン(`music`)はセッションスニペットの「曲」を表すために使う。

→ ユーザーのアバターは人型(`user`)が基本、音符は楽曲を表す時に使う。混同しないこと。

## このドキュメントの確認チェックリスト

実装後、以下をすべて確認:

### 構造
- [ ] ボトムナビが4項目(タイムライン/投稿/メッセージ/マイページ)
- [ ] メッセージタブのアイコンが `message-square` か `message-circle`
- [ ] タイトルが「メッセージ」(「通知」ではない)
- [ ] 「チャット中」サブセクションが無い、フラットなリスト

### メッセージ一覧の各行
- [ ] アバター右下に役割マーク(host=赤disc / pending=オレンジclock / guest=赤users)
- [ ] 右上に時間表示
- [ ] プレビュー行が4状態(alert/pending/通常/empty)を表現
- [ ] 未読バッジが赤丸で表示
- [ ] アバタータップでプロフィールへ、行タップでチャットへ

### チャットルーム
- [ ] 上部にセッションスニペット(波形プレイヤー付き)
- [ ] 未承認アンサーカード(音源 + メッセージ + あとで/承認)
- [ ] 承認時に保留中バーが出現
- [ ] チャット区切り線「── チャット ──」
- [ ] クイックリプライタブ4種類(うち2つはdisabled)
- [ ] 挨拶ピッカー、パート投票バブル
- [ ] ヘッダー右に参加人数(👥3)

### システムメッセージ
- [ ] 承認時に「○○さんと、会えそうですね 🎵」が表示される
- [ ] 中央寄せ、薄いグレーの控えめな表示

### バブル
- [ ] 相手バブル: 左上だけ尖った角丸、グレー背景
- [ ] 自分バブル: 右上だけ尖った角丸、赤背景、ほのかな影
- [ ] バブル最大幅80%
- [ ] 相手のバブル上に名前、自分のバブル下に「あなた」

**最後に**: メッセージ機能はサービスの本質「**スタジオへ行く約束をする場**」。プロトの設計を忠実に再現することで、初心者でも「スタジオの日程相談」までスムーズに進める体験を作れます。
